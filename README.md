# Customer Churn Prediction using Machine Learning

## Project Overview

This project predicts customer churn in a telecommunications company using Machine Learning techniques. The goal is to identify customers who are likely to discontinue services and help improve customer retention.

## Dataset

* Telco Customer Churn Dataset
* Records: 7043
* Features: 21
* Target Variable: Churn

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* VS Code

## Machine Learning Workflow

1. Data Preparation
2. Data Splitting
3. Feature Selection
4. Model Selection
5. Model Training
6. Model Evaluation

## Model Used

Random Forest Classifier

## Results

* Accuracy: 79.21%
* Precision: 65%
* Recall: 46%
* F1 Score: 54%
* ROC-AUC Score: 83.44%
